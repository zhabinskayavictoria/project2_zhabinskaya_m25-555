# Примитивная база данных 💥
Это консольная база данных на Python. Программа поддерживает создание таблиц, операции CRUD,
а также реализует обработку ошибок, подтверждение опасных действий, логирование и кэширование.

База данных хранит данные о всех таблицах и данные таблиц в виде JSON-файлов.

# Управление таблицами :computer:
| Команда | Описание | 
|----------------|---------|
| create_table \<имя_таблицы> \<столбец1:тип> .. | создать таблицу|
| list_tables| показать список всех таблиц|
| drop_table \<имя_таблицы>  | удалить таблицу|
| help  | справочная информация|
| exit |  выход из программы|

Поддерживаемые типы данных для столбцов таблиц: `int, str, bool`.

Если пользователь не указал столбец `ID:int` при создании таблицы, то он автоматически добавляется в таблицу.

# Новые возможности 🔖

### - Обработка ошибок базы данных
Декоратор `@handle_db_errors` автоматически перехватывает распространенные исключения при работе с базой данных: KeyError, ValueError, FileNotFoundError.

Этот декоратор оборачивает функции в блок try...except, выводя информативные сообщения об ошибках. Теперь ручные блоки try...except удалены из db_core для упрощения кода. 

Применен ко всем функциям, которые могут вызвать эти исключения в `core.py`.

### - Подтверждение опасных действий
Декоратор `@confirm_action(action_name)` запрашивает у пользователя подтверждение перед выполнением рискованных операций. 

Он принимает название действия как аргумент и выводит сообщение в формате:  `"Вы уверены, что хотите выполнить 'удаление таблицы'? [y/n]:"`

Если введено "y", то функция выполняется, иначе операция отменяется без изменений.

Применен к функциям: `drop_table` и `delete.`

### - Логирование времени выполнения

Декоратор `@log_time` измеряет время выполнения функции с помощью time.monotonic() и выводит результат в консоль: `"Функция <имя_функции> выполнилась за X.XXX секунд."`

Применен к "медленным" операциям с файлами: `select` и `insert`.

### - Кэширование результатов запросов
Функция `create_cacher()` создает замыкание для простого кэширования. 

Внутренняя функция `cache_result(key, value_func)`:

  ⦁ Проверяет наличие результата в словаре-кэше по ключу.

  ⦁ Если кэш пуст, вызывает value_func для получения данных, сохраняет результат и возвращает его.

  ⦁ Последующие вызовы с тем же ключом возвращают кэшированный результат.

Интегрировано в операцию `select`: одинаковые запросы теперь кэшируются, ускоряя повторные вызовы без повторного чтения файлов.
